# ATM Machine

A simple **ATM Machine application built in Java** to demonstrate fundamental **Object-Oriented Programming (OOP)** concepts.

## 📌 About the Project

This project simulates basic ATM operations through a console-based Java application. The user can enter a PIN and perform operations such as checking their balance, withdrawing money, depositing money, and exiting the application.

The project was created as part of my journey of learning and practicing **Java and Object-Oriented Programming**.

## ✨ Features

* 🔐 PIN authentication
* 💰 Check account balance
* 💵 Withdraw money
* 💳 Deposit money
* 🚪 Exit the ATM
* 🖥️ Console-based interactive interface

## 🛠️ Technologies Used

* **Java**
* **Object-Oriented Programming (OOP)**
* **Java Scanner** for user input

## 🧠 OOP Concepts Practiced

This project provides practice with:

* Classes and Objects
* Encapsulation
* Methods
* Variables and Data Types
* Conditional Statements
* Loops
* User Input using `Scanner`

## ▶️ How It Works

The program starts by asking the user to enter their PIN.

After successful authentication, the ATM displays a menu from which the user can select an operation:

1. Check Balance
2. Withdraw Money
3. Deposit Money
4. Exit

The selected operation is then performed and the updated information is displayed in the console.
